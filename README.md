# 🤖 Project 1: RuleBot AI Chatbot

## 📌 Project Overview

RuleBot AI is a simple **rule-based artificial intelligence chatbot** developed using Python.

The chatbot uses predefined rules, conditional statements, and decision-making logic to simulate human-like conversations. It responds to user inputs based on programmed patterns and commands.

This project was developed as part of the **DecodeLabs AI Internship** to demonstrate basic AI concepts, Python programming, and chatbot development.

---

# 🎯 Project Objectives

The main objectives of this project are:

- Understand basic Artificial Intelligence concepts
- Develop a simple rule-based chatbot
- Implement decision-making using Python `if-elif-else` statements
- Create an interactive user conversation system
- Practice loops, functions, and user input handling
